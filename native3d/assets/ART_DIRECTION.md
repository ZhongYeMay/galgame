# 《夏日未寄》高精度 3D 美术制作规范

此文档是模型的强制验收依据，不表示已经生成了模型。

## 唯一可接受的目标

- **3D 原生模型**：完整背面与侧面几何、独立材质、UV、细节，不允许相机贴图、投影法、人物 PlaneMesh 或低多边形方块替代。
- **原版视觉一致**：角色发型、面部比例、服装轮廓与配色以 `site/assets/retro/{mio,nagi,shiori}-0.webp` 原画为唯一视觉参考；环境参考 `coast.webp` / `studio.webp` / `bookshop.webp`。
- **二次元美术**：细腻赛璐璐光影、温和偏紫粉的夕阳和清晰的手绘材质。不追求真实皮肤毛孔、金属塑料感或泛滥的描边。
- **不偷换风格**：AI 结果只作为网格初稿，人工修模、重拓扑、材质绘制、骨骼绑定、动画、性能优化通过后才导入正式游戏。

## 地图与碰撞

- 世界边界固定：X、Z 坐标控制在 `[-35,35]` 米区间（后续按正式设计修改），不生成无限地图。
- 主场景中的地面、海滨道路、电车道口、建筑实体都应有碰撞。
- GLB 中应包含**不可见的工程碰撞网格**：名称以 `COL_` 开头，例如 `COL_Ground`、`COL_BookshopWall`。它们是物理数据，不是玩家能看到的粗糙方块。
- 碰撞网格须根据真正的可见几何精修；不可造成穿模、悬空或挡住正确道路。
- 游戏会从 `COL_` 网格创建物理碰撞；缺失时拒绝宣称完整可玩。

## 美术验收步骤

模型交付后逐一审核：正面、侧面、背面和斜 45° 摄像机视角；场景需有俯视图、室内图和实际第三人称游玩截图。检查衣服层次、眼睛与脸部、头发体块、建筑尺度、地面连续性、角色脚底触地和实际帧率。

目标质量是**完整、精细的日式第三人称 3D 探索游戏**，不是特定商业游戏的原始素材或模型复制品。

## AI 生成工作流

可使用已获授权的文生/图生 3D 工具基于**本项目自己的原画**生成初稿，然后经过 DCC 工具修模。单张 2D 图片不能自动可靠恢复背面与遮挡部分，需多视角建模和人工审查。

模型真实生成后，可运行：
```bash
python native3d/tools/stage_glb.py mio ./my_mio.glb --source "原创 AI 3D 初稿+人工修模" --license "原创资产，已确认商业使用许可"
```
脚本会写入 `approved=false` 的验收记录。经人工目视检查且明确授权后，填写 `reviewed_by`、`notes` 并改为 `approved=true`。不得让 AI 自动填写“已验收”。

## 发布规范

GitHub Actions 首先运行质量门槛，不通过时**不给下载链接**。通过也只证明结构和人工审核记录齐全，不等于 Android 真机已测试。真实导出后仍需人工检查 Android 安装/触控/性能/权限、Windows 安装/键鼠、全部角色动画与在线 AI 行为。
