# 夏日未寄 — 夏の便り

日式纯爱网页视觉小说，使用 AI 生成的场景与人物原画。

- 三条成年角色故事线、六个结局。
- 人物表情与姿态随对白变化，场景仅随地点切换。
- 存读档、回看、自动播放、已读快进与背景音乐。
- 可选非露骨成熟恋爱尾声，默认关闭。
- 固定 16:9 电脑版界面；手机提示进入全屏并使用横向画布。

## 在线游玩

https://zhongyemay.github.io/galgame/

点击对白或按空格推进，Esc 关闭面板或隐藏界面。存档仅保存在当前浏览器。

## 文件与部署

游戏文件与图片位于 `site/`，无需安装依赖或构建。推送到 `main` 后，由 `.github/workflows/pages.yml` 自动发布至 GitHub Pages。

所有图片均为 AI 生成的 WebP 位图，不包含矢量图片。无角色配音；背景音乐由浏览器实时合成。部分移动浏览器不支持网页全屏或方向锁定，会提供横向画布与手动全屏提示。
