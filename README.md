# 夏日未寄 — 夏の便り

复古日式纯爱网页视觉小说，采用赛璐璐角色、蓝紫暮色场景和 AI 生成位图原画。

- 共同篇四章、后续篇五章与尾声；共约 2 万字、778 段对白与剧情选择节点。
- 没有开局选线或角色直达入口，四天共同剧情中的七次日常选择会自然影响后续相处。
- 个人篇中的多次选择共同决定结局，保留六个结局；不显示好感度或结局预告。
- 人物表情与姿态随对白变化，场景仅随地点切换。
- 存读档、回看、自动播放、已读快进与背景音乐。
- 可选非露骨成熟恋爱尾声，默认关闭。
- 固定 16:9 电脑版界面；手机提示 3 秒后自动消失，进入横向画布，可点击全屏按钮。

## 在线游玩

https://zhongyemay.github.io/galgame/

点击对白或按空格推进，Esc 关闭面板或隐藏界面。日记只记录已读章节，不能用来跳选故事线。存档仅保存在当前浏览器，包含选择记录和当前关系进展。

章节版存档与原短篇结构不同：旧存档仍保留在浏览器里，读取时会从新共同篇开始，避免直接绕过共同剧情。阅读速度因人而异；目前是扩写的章节版，还不是十几小时的商业长篇。

## 文件与部署

游戏文件与图片位于 `site/`，无需安装依赖或构建。推送到 `main` 后，由 `.github/workflows/pages.yml` 自动发布至 GitHub Pages。

全部场景与角色采用复古日式动画风格，所有图片均为 AI 生成的 WebP 位图，不包含矢量图片。无角色配音；背景音乐由浏览器实时合成。部分移动浏览器不支持网页全屏或方向锁定，会提供横向画布与手动全屏提示。
