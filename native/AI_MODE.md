# MayOS《夏日未寄》DeepSeek AI 即兴对白（测试功能）

这是原生 SDL2 游戏的可选模式，不是网页聊天，也不会替换主线剧情。常规剧情中按 T 开启，Esc 返回原版剧情，输入消息后按 Enter 发送。

## 人物设定

- 白石澪：海边电台的节目制作人，围绕放送室和节目的日常对话。
- 橘凪：回乡采风的摄影师，围绕海边、旅程和照片的话题。
- 月島栞：旧书店店主，围绕书、文字与日常闲聊。

这些人设直接从未修改的 site/story.js 导出；系统指令与当前场景一同送入 API，帮助生成贴合人物特点的即兴对白。玩家与 AI 的自由对话不改写 STORY 节点、不更改结局。

## API 密钥保护

默认模型：deepseek-flash；官方接口：https://api.deepseek.com/chat/completions 。

**API Key 严禁提交到 GitHub、源文件、游戏素材或公共网页。**
程序只读取本机进程环境变量 DEEPSEEK_API_KEY。不在日志中打印密钥。

Linux 临时输入测试密钥（输入时不显示）：

    read -rsp "DeepSeek API Key: " DEEPSEEK_API_KEY
    echo
    export DEEPSEEK_API_KEY
    python3 launch_native.py
    unset DEEPSEEK_API_KEY

上面的启动命令适用于 GitHub Actions 成功构建后解压出来的 Linux 发布目录。使用仓库源码构建时，请先按 native/README.md 编译程序，再运行对应可执行文件。

通过桌面图标启动时，桌面环境需要预先配置该环境变量。若没有密钥，原版剧情仍可玩，AI 模式会提示未配置。测试后请主动在 DeepSeek 控制台撤销该测试密钥；unset 仅清除当前 shell 中的值，不会让密钥失效。

## 运行与限制

- 每轮限制最多 180 生成 token，保留最近 12 条本地 AI 消息，避免无限增长的费用。
- 最多同时执行一个请求，请求采用独立线程，最长等待 30 秒，网络错误会显示简短提示。
- 切换女主时会隔离 AI 历史；自由对话只在内存保存，不进入原版存档。
- 请求发送当前人物设定、场景文字、玩家输入和本次会话近期 AI 历史。请不要输入敏感个人资料。
- AI 回复尽量变化，但无法保证绝对不重复。
- AI 功能联网使用，原版剧情可离线运行。
- 此原生功能不等于网页端支持；公开的 GitHub Pages 版本需要另设有访问控制和限额的服务端代理，禁止直接将密钥嵌入静态网页。
- 对话提示要求全年龄、非露骨、非排他性日常内容。
- CI 单元测试不调用真实 DeepSeek，也没有真实 API 消耗。使用有效测试密钥的端到端验收尚待完成。
